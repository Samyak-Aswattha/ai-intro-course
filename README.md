# 人工智能导论 · 交互式课程网站

面向人文社科大一新生的 AI 通识课配套网站。设计理念来自 kimi-k3-learn：**不是让你看懂，是让你没法骗自己**。

## 快速开始

```bash
cd 课程网站
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 内容规模

- **9 章 41 节**概念讲解，内容融合 12 份课程课件原文（通识课四讲、《AI 启示录》《智能的定义》《大模型运作原理》、实践课讲义等）
- **58 个交互演示**：21 个真实可运行实验室（含"故意弄坏"开关）+ 6 个 Three.js 3D 场景 + 31 个 2D 交互/动画（信息茧房/规格博弈/辩论图谱/评审模拟器/特征层级/规模法则/思维链剧场/Agent 协议星图等）
- **205 题**误解驱动题库：选择/判断/填空即时判分，简答/论述/案例自评
- **间隔重复**（简化 SM-2）：错题按 1/2/4/8…天重现
- **划线提问包**：不懂/重要/存疑/深挖 四色标注，一键生成提问包
- **AI 课程助教**：OpenAI 兼容接口（默认智谱 GLM），无 Key 自动降级 FAQ 检索
- **纯静态零运维**：无后端、无 CDN、离线可用（视频除外）

## 维护入口

| 想改什么 | 改哪里 |
|---|---|
| 课文内容 | `data/concepts/01~09.js` |
| 章节结构/加小节 | `js/data.js`（`CHAPTERS`）+ `node scripts/gen-pages.mjs` |
| 题库 | `data/quiz/*.js` 或 `scripts/extra-questions.json` |
| FAQ | `data/faq.js` |
| 参考资料 | `data/references.js` |
| 演示 | `demos/<名称>/index.html`（自包含，共享 `_shared/demo.css/js`） |
