部署命令卡
1安装 Ollama：官网 ollama.com 下载对应系统安装包（Win/Mac 一路下一步）
2打开终端（Mac：终端 app；Win：PowerShell），粘贴上面的命令回车，等待下载（模型文件 4–8 GB）
3下载完自动进入对话——直接用中文聊天测试。输入 /bye 退出
4进阶：Ollama 常驻后（ollama serve），在 AnythingLLM / Cherry Studio 里填 http://localhost:11434 即可把它当作本地大脑搭知识库
为什么本地跑
① 隐私：日记、未发表稿件、他人数据不出本机
② 离线：教室无网也能用
③ 自主：不受停服、涨价、审查摆布

模型名里的 q4 = 4 比特量化：体积 ÷4，能力略降、速度更快——性价比甜点。
经验：Apple Silicon 用统一内存（把 RAM 拉高试试）；NVIDIA 看显存；纯 CPU 只推荐 3B 以下。
