# 《人工智能导论》课程网站 · 使用与部署说明

> 一个纯静态、零运维、离线可用的交互式课程网站。
> 9 章 41 节 · 58 个可运行演示（含 6 个 3D 场景）· 205 题误解驱动题库 · 间隔重复 · 划线提问包 · AI 课程助教。

---

## 一、目录结构

```
课程网站/
├── index.html          # 门户首页（课程地图/学习路径/进度）
├── notes.html          # 我的笔记（划线汇总/导出 Markdown）
├── css/                # 设计系统（site.css + components.css）
├── js/                 # 应用引擎（外壳/搜索/笔记/AI 助教/测评/渲染器）
│   └── data.js         # 章节树 CHAPTERS（全站导航的单一来源）
├── data/
│   ├── concepts/01~09  # 九章知识点内容（改内容只动这里）
│   ├── quiz/01~09      # 章节题库（源自题库 docx 转换+去重+补充）
│   ├── faq.js          # 答疑 FAQ（约 40 条，按主题分类）
│   └── references.js   # 参考资料
├── modules/{intro,foundations,debates,practice}/   # 章节页面
├── demos/              # 58 个交互演示（每个独立目录，可单独打开）
├── quiz/ faq/ references/   # 测评/答疑/资料中心页面
├── assets/             # 图片/视频/本地库（含 Three.js）
├── scripts/            # 开发用脚本（页面生成/题库转换）
└── docs/               # 本说明 + AI 代理脚本
```

## 二、本地预览

网站是纯静态文件，但使用了 ES Modules，**双击 index.html 无法直接运行**（浏览器安全限制）。用任意静态服务器：

```bash
cd 课程网站
python3 scripts/serve.py 8000     # 推荐：自带 no-cache，改文件即刻生效
# 浏览器打开 http://localhost:8000
# （用 python3 -m http.server 也可以，但它不发缓存头——改版后需硬刷新 ⌘⇧R）
```

或使用 VS Code 的 Live Server 插件、`npx serve` 等。

## 三、部署

### 方案 A：校内服务器（推荐）
把 `课程网站/` 整个目录复制到服务器任意静态目录即可（nginx/apache 的 html 目录、或直接挂在内网共享）。**注意：**
- 视频文件共约 700MB（assets/video/），若空间紧张可删减 `laozhang-story.mov`（134MB）与 `demo-7e.mp4`（63MB）。
- 无需任何后端、数据库、Node 环境。

### 方案 B：GitHub Pages
1. 新建仓库，推送除视频外的全部文件（视频超 GitHub 100MB 单文件限制，`laozhang-story.mov` 必须排除）。
2. Settings → Pages → 选 main 分支根目录。
3. 视频可另存网盘/图床后改 `data/concepts/*.js` 中的 video src。

### 方案 C：U 盘/局域网直传
整包拷贝即可离线运行（唯一需要网络的：nn-playground-guide 内嵌的 TensorFlow Playground 外链、外部论文链接）。

## 四、日常维护（教师）

### 改课程内容
- **改文字/加段落**：编辑 `data/concepts/章节号.js`，块类型见文件内已有示例（p/callout/demo/formula/terms/compare/timeline/figure/quote/list）。保存刷新即生效。
- **加小节**：在 `js/data.js` 的 `CHAPTERS` 对应章的 sections 里加一行，然后运行 `node scripts/gen-pages.mjs` 生成页面壳，再在 concepts 里写内容。
- **改题库**：编辑 `data/quiz/章节号.js`（JSON 数组），或修改 `scripts/extra-questions.json` 后重跑 `python3 scripts/parse-quiz.py`（需先用 textutil 重新导出题库 txt）。

### 学生数据说明
所有学习记录（阅读进度/答题/错题/间隔重复/笔记）保存在**学生本机浏览器**的 localStorage：
- 换浏览器/设备/清除浏览数据 = 记录清零（这是纯静态的取舍）。
- 笔记可通过「我的笔记 → 导出 Markdown」带走。

## 五、AI 课程助教配置

### 学生自助开启（推荐）
1. 点击任意页面右下角 🤖 → 面板右上 ⚙️。
2. 填写 OpenAI 兼容接口：
   - **接口地址**：`https://open.bigmodel.cn/api/paas/v4`（智谱，注册送额度）
   - **模型**：`glm-4.6`（或 `glm-4-flash` 免费档）
   - **API Key**：控制台获取
3. 保存即可在站内直接问答。Key 只存在本机浏览器。

### CORS 说明
部分接口不允许浏览器直连（跨域）。如遇 `CORS` 报错，部署 `docs/ai-proxy-worker.js`：

```bash
# Cloudflare Workers 免费方案（约 3 分钟）
1. dash.cloudflare.com → Workers & Pages → Create Worker
2. 粘贴 ai-proxy-worker.js 全文 → Deploy
3. 把学生设置里的接口地址改为 https://你的worker.workers.dev/v4
```

### 不配置 Key 也能用
- 无 Key 时 AI 面板自动降级为 **FAQ 检索**（中文模糊匹配）。
- 划线生成的**提问包**可粘贴到任何大模型网页版（ChatGPT/Kimi/豆包/智信等）。

## 六、浏览器兼容

- Chrome / Edge / Safari / Firefox 近三年版本均可。
- 3D 演示需要 WebGL（所有现代浏览器默认支持）。
- 移动端可用（响应式布局），实验室类演示建议横屏。

## 七、已知边界

1. **联网需求**：仅 TensorFlow Playground 外链、外部论文/课程链接需要网络；其余全离线。
2. **AI 判分**：填空题为精确匹配（逗号分隔多空）；简答/论述为自评制（这本身是教学设计）。
3. **题库规模**：205 题（原题库去重后 + `scripts/extra-questions.json` 持续补充，含 ch02/ch04 的均衡补充），题量仍可随时在 quiz/*.js 或 extra-questions.json 中补充。
